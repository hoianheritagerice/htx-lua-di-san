===========================================================
LƯU Ý QUAN TRỌNG
===========================================================

1. TÊN FILE phải giống hệt: chữ thường, gạch ngang, KHÔNG dấu tiếng Việt,
   KHÔNG khoảng trắng. Đuôi .jpg viết thường.
   Sai một ký tự là trang không tìm thấy ảnh.

2. PHẢI NÉN ẢNH trước khi tải lên:
   - Ảnh nền lớn (hero-*, dong-*, gt-*): rộng 1920 px, dưới 400 KB
   - Ảnh nội dung (cau-chuyen, ve-chung-toi, goi-*): rộng 1200-1400 px, dưới 300 KB
   - Ảnh chụp điện thoại thường nặng 3-5 MB -> bắt buộc nén, nếu không
     khách mở trang bằng 4G sẽ rất chậm.
   - Nén miễn phí: vào squoosh.app, kéo ảnh vào, chọn Quality ~75, tải về.

3. CHƯA CÓ ẢNH cũng không sao, trang vẫn chạy bình thường:
   - Chỗ ảnh nền lớn: hiện nền xanh sọc, góc dưới bên phải có nhãn mờ
     ghi "Chưa có ảnh nền: img/....jpg"
   - Chỗ ảnh nội dung: hiện ô màu đất, giữa ô ghi tên file cần đặt
   Nghĩa là CỨ MỞ TRANG WEB LÊN LÀ BIẾT CÒN THIẾU ẢNH NÀO — không cần
   mở tài liệu này. Bỏ ảnh vào lúc nào hiện lúc đó, nhãn tự biến mất.

4. CÁCH TẢI LÊN GITHUB (làm được cả trên điện thoại):
   Mở repo -> bấm vào thư mục img -> Add file -> Upload files ->
   chọn ảnh -> Commit changes.
   Khoảng 1-2 phút sau trang tự hiện ảnh mới. Nếu vẫn thấy ảnh cũ:
   tải lại trang bằng Ctrl+F5 (máy tính) hoặc xoá cache trình duyệt
   (điện thoại) — GitHub Pages có đệm vài phút.

5. THAY ẢNH sau này: tải lên file MỚI TRÙNG TÊN CŨ, GitHub tự ghi đè.
   Không cần xoá file cũ, không cần sửa code.
